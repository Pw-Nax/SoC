# SoC Multicore en FPGA: de la instrucción RISC-V al bootloader

Curso de Fundación Fulgor. Docentes: Daniel Rosso - Pablo Madoery.

Material para estudiantes. El contenido se libera clase a clase, a medida
que avanza el curso.

## Estructura

Cada jornada liberada tiene sus slides (`slides.pdf`) y el laboratorio
para completar (`lab/`).

- `jornada_1_isa_toolchain/` — ISA RISC-V y toolchain (spike)
- `jornada_2_soc_minimo/` — SoC mínimo: PicoRV32 + memorias
- `jornada_3_firmware/` — Firmware bare-metal y compilación
- `jornada_4_mailbox_prbs/` — SoC 2-core con mailbox (BERT PRBS)
- `jornada_5_bootloader_prbs/` — Bootloader y carga de firmware

- `comun/` — cronograma del curso, guía de instalación previa y notas útiles (JTAG/UART externo)
